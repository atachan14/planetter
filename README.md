# Planetter

Java / JSP / Servlet / MySQLを使用して制作した、SNSを想定したWebアプリです。

公共職業訓練でプログラミングを学び始めて約2か月の時期に、学習課題として制作しました。

制作当時はローカル環境でのみ動作確認を行い、現在は学習過程としてソースコードを公開しています。

## 概要

ユーザーは座標を移動しながら、各座標の投稿を発見したり、新しい投稿を配置したり、情報構造の拡張や投稿情報の削除などを行うことができます。

空間はGalaxyとPlanetからなる2階層の2次元座標で構成されています。通常の移動ではPlanet内を移動し、小型ロケットによってGalaxy座標を移動できるようになっています。対象のGalaxy座標に既存Planetが存在しない場合は、リソースを消費して新規Planetを作成します。

Planet/Account単位でランダムなカードを獲得する仕組みと、一部のカードによるPlanet/Account単位での機能の拡張を実装しています。

## 使用技術

- Java
- JSP / Servlet
- JDBC
- MySQL
- HTML / CSS
  
## 制作経緯と設計意図

主にServletとDBの学習のためSNSを題材として、ユーザーが歩いて投稿を発見していくというコンセプトから制作を開始しました。

SQLの使用経験としてDELETEコマンドを組み込みたかったため、他者の投稿や他者のアカウントを削除できる仕様を実装しました。

投稿やアカウントが簡単に削除される仕様によって、ユーザーは他ユーザーから削除されない位置に逃げる必要ができたため、Galaxy座標という上位階層を移動できるようにしました。

投稿を発見していくという最初のコンセプトを大事にするため、座標の移動では、慣れない場所では迷子になれるようなUIを目指しました。

お互いに相手を削除できる状況下で、それでも信頼し合える仲間ができてほしいという思いが強まってきたため、また、座標を移動する意味を失わせたくなかったため、グループやフレンドのように機能を制限する契約やアクセスを拡張するための機能は実装しませんでした。

代わりに、Planetを共有財産としてPlanet単位でコミュニティが形成されたら面白そうな感じがしてきたので、また、アカウントが削除されないように逃げる理由を強化したかったため、Planet/Account単位での恒久的な機能拡張システムを実装しました。

一人のユーザーによってコミュニティが丸ごと壊滅するのは酷に思えたので、仲間を守るための自爆装置を実装しました。

訓練校での課題提出日となったため、ここで制作を終了としました。
