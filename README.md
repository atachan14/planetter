# Planetter

Java / JSP / Servlet / MySQLを使用して制作した、ゲーム要素のあるSNSです。

公共職業訓練でプログラミングを学び始めて約2か月の時期に、学習課題として制作しました。

## 概要

ユーザーは2次元座標で構成されたPlanet内を歩き、各座標に置かれた投稿を発見したり、何もない座標に新しい投稿を配置したりできます。

1つの投稿はPageへ拡張することができ、同じ座標に複数の投稿をまとめられます。

Planet自体もGalaxy上の座標に配置されており、新しいPlanetの作成やPlanet間の移動ができます。

## 使用技術

- Java
- JSP / Servlet
- JDBC
- MySQL
- HTML / CSS
